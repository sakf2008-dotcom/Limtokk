# علم توك | IlmTok — اسحب وتعلّم

منصة فيديوهات تعليمية قصيرة عربية (تطبيق ويب تقدّمي — PWA). تجربة شبيهة بالتطبيقات المعروفة للفيديوهات القصيرة، بهوية أصلية ومحتوى تعليمي، و**بدون تسجيل حسابات للزوار**.

- **للمالك:** انظر `PROGRESS.md` لما اكتمل وما يبقى، و`DEPLOYMENT.md` لخطوات النشر.
- **للمطوّر:** المعمارية أدناه، والأوامر في آخر الملف.

## المبادئ

1. لا تسجيل ولا تسجيل دخول ولا بريد ولا رقم هاتف للزوار أو المساهمين. الاسم المستعار يكفي.
2. كل فيديو يُرفع يبقى **غير مرئي للعامة** حتى توافق عليه مراجعة بشرية.
3. الحدود وحماية الإساءة تُفرض على **الخادم**، لا في الواجهة فقط.
4. لا يوجد ذكاء اصطناعي للإشراف، ولا يُدّعى ذلك. الترتيب «لك» بسيط وشفاف.
5. لا تُخزَّن أي كلمات مرور أو مفاتيح في الشيفرة.

## المعمارية

```
src/
  app/                    صفحات App Router ومسارات API (app/api/...)
  components/             واجهات: التغذية، الرفع، الاستكشاف، الإدارة، مكوّنات مشتركة
  lib/
    domain/               أنواع مشتركة ودوال نص عربي (لا تعتمد على Node أو DOM)
    client/               تخزين محلي، عميل API، حلّال إثبات العمل، المكتبة المحلية
    server/
      db/                 المخطط (schema.ts)، عميل قاعدة البيانات، البذور التجريبية
      repo/               استعلامات SQL (الفيديوهات، التفاعل، الإدارة)
      services/           منطق الأعمال: الرفع، الإشراف، التفاعل، التنظيف
      media/mp4.ts        مُحلّل بنية MP4/MOV (قراءة الرؤوس فقط)
      storage/            تجريد التخزين: Supabase Storage أو القرص المحلي
      auth/               مصادقة المشرف (جلسة HMAC، كوكي مشفّر)
      rate-limit.ts       حدود الطلبات داخل قاعدة البيانات (تعمل عبر عدة خوادم)
      pow.ts              إثبات العمل ضد البوتات (مرة واحدة لكل تحدٍّ)
db/                       (المخطط الفعلي في src/lib/server/db/schema.ts)
public/                   الأيقونات، Service Worker، الفيديوهات التجريبية
tests/                    unit / integration / e2e
```

### قاعدة البيانات
- **نفس SQL على مكانين:** PGlite (PostgreSQL داخل العملية) للوضع التجريبي والاختبارات، وPostgreSQL من Supabase للإنتاج. هذا يعني أن الاختبارات تنفّذ SQL الفعلي.
- **RLS مفعّل على كل الجداول** بلا أي صلاحية كتابة لـ anon وauthenticated. العرض العام `public_videos` يعرض الصفوف المنشورة فقط وبدون حقول حساسة.
- الترحيلات تُطبَّق تلقائيًا عند أول طلب، بقفل استشاري (advisory lock) يمنع السباق بين الخوادم المتعددة.

### الرفع (الخط الزمني للحماية)
1. `POST /api/uploads`: حدود المعدل (IP وجهاز)، الحظر المؤقت، حد الإرسال المعلّق، حد يومي للجهاز والنظام، حد التخزين، نوع الملف، الحجم، إثبات العمل، ثم رمز ملكية عشوائي ورابط رفع قصير الأجل إلى مساحة **خاصة**.
2. الرفع المباشر إلى التخزين (أو مسار `PUT` المحلي في الوضع التجريبي).
3. `POST /api/uploads/:id/complete`: التحقق من **الحجم الفعلي** والبنية والمدة والأبعاد والترميز. الفشل يحذف الملف فورًا.
4. الانتظار للمراجعة البشرية. الموافقة تنقل الملف إلى مساحة **عامة** وتجعله مرئيًا.

## الاختبارات

- **Vitest (75 اختبارًا):** مُحلّل MP4 (صالح وتالف وضار)، تحليل النص العربي، تطبيق حدود الرفع، إثبات العمل ومنع إعادة الاستخدام، رموز الملكية والاسترداد، Range للفيديو، المشرف (جلسة، كوكي، طلبات عبر المواقع، حد المحاولات)، والتفاعل (الإعجاب، المشاهدة، التعليقات، البلاغات).
- **Playwright (21 اختبارًا):** التغذية على شاشة iPhone، تشغيل فيديو واحد، التمرير، النقر والنقر المزدوج، التنقل، البحث، الاستكشاف، رفض الملفات غير المدعومة، بوابة المشرف، ملف PWA.

## الأمان

تفاصيل الضوابط في `PROGRESS.md` (القسم 2 و4). أهمها: HMAC لكل المعرّفات والرموز مع فصل الأغراض، مقارنة زمنية ثابتة، كوكيات HttpOnly وSameSite=Strict، رؤوس أمان وCSP، عدم تخزين IP الخام، وحدود معدل عبر قاعدة البيانات.

## ترخيص المحتوى

الفيديوهات التجريبية من إنتاج فريق المشروع وتحمل علامة «محتوى تجريبي». لا توجد مواد من أطراف ثالثة.
